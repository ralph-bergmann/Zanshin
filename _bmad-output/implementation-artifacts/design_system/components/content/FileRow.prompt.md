The name in `--text`; after it its quiet word, 10.5px sans: added **new** in `--add` and deleted **deleted** in `--rem`, both at .85; renamed or copied **from <old>** in `--text-faint` — the old file name while the folder is the same, else the whole old path; a modification has no word. The word sits inside the name and gives way with it. Then the folder with its `/` in `--text-faint`, its head (everything up to the last folder) giving way first, then the last folder, then the name, each with its own ellipsis. A rename shows its new name and folder; the tooltip is the path (`old → new` for a rename).
- **Check column** (`selectable`): a 22px column at the row's left edge, the box (sm) centred, not indented; the indent follows it. Not selectable (immutable change, operation view): no column, left padding 8. **On demand:** inside a pane marked `.zs-check-reveal` an unchecked box is at opacity 0 until the pointer is over that pane or focus is inside it; picked and mixed boxes always show. Only the opacity changes — the box keeps its place, its focus, its label and its click, so no row moves. Each pane (the file list, the code) is its own scope. Adding `.is-revealed` to the pane forces every box shown (a catalogue or screenshot without hover).
