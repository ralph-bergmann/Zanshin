The inspector's diff block — path, layout toggle and "Viewed" over the hunks of one file, as `jj diff`'s default color-words lines.

~~~jsx
<DiffView file="lib/onboarding/swipe_controller.dart" viewed={v} onViewedChange={setV}
  tools={<Segmented size="sm" value={mode} onChange={setMode} options={[{ value: "unified", icon: "split-inline", title: "Unified" }, { value: "split", icon: "split-side", title: "Side by side" }]}/>}>
  <DiffHunk context="class SwipeController" mode={mode} selectable selected lines={[" 12:12|  final double threshold;", "~13:13|  void onEnd({+DragEndDetails d+}) {", "+:14|{+    _commit();+}"]}/>
</DiffView>
~~~

- Surface: `--code-bg` well, 1px `--fl-border`, 12px radius; JetBrains Mono 11px / 1.65.
- **Rows** (Story 5.10): each row shows its left (old) and right (new) line number, right-aligned in columns as wide as the hunk's largest number and outside the selection, then its text — no sigil column. Context: faint numbers, muted text. Removed: left number and text in `--rem` on `--rem-bg`. Added: right number and text in `--add` on `--add-bg`. **Changed** (an inlined line holding both sides' words): both numbers in their hue (left `--rem`, right `--add`), no fill, `--text` ink. A conflict header (`diff.color-words.conflict = "pair"`): `--text-dim`, no numbers. Hunk headers in `--hunk` on **`--hunk-bg`** (data — not `--accent-soft`, which is selection). Minus sign is a real "−".
- **Lines** are written `"<kind><left>:<right>|<text>"`: `" 12:12|…"` context, `"-14:|…"` removed, `"+:14|…"` added, `"~13:13|…"` changed, `"#|<<<<<<< Created conflict"` a header. One old line spread over several new ones repeats its left number (`"~13:13|…"`, `"~13:14|…"`). Changed words: `[-…-]` around a left-side run, `{+…+}` around a right-side one, on any line. A string has no escape: code that holds `[-`, `-]`, `{+` or `+}` (`s[-3:]`, `i++}`) goes in the object form `{ t, l, r, s, runs }`, `runs` as `[text, "rem" | "add" | null]`. Older git strings (`"+…"`, `"-…"`, `" …"`) still parse, without numbers.
- **Changed words**: each run lies on the stronger tint of its side's hue (`--rem-word-bg` / `--add-word-bg`, the line's full height) and its glyphs turn `--text` (red or green text on a stronger tint falls under 4.5:1 — Control states rule 6). A changed line always shows both colours; the removed tint is darker and the added tint lighter, so a reader who sees red and green alike still tells them apart. A removed or added line whose unchanged text is only blanks — an inserted line, a block over the inline limit's new lines, a new or deleted file — keeps no marks: its fill says it all. In the app the lines and runs are exactly what `jj diff` prints with no `ui.diff-formatter` (jj-lib's line and word diff, the CLI's inline rule: a block is inlined unless its words alternate between the sides more often than `diff.color-words.max-inline-alternation`, default 3), painted under the text, so a selection's highlight lies on top of a mark.
- **Changed words switch** (Story 5.14, Settings › General › Diffs › "Changed words", on by default): `wordMarks={false}` drops the tint everywhere. Only a changed line keeps its runs, as glyphs in their side's hue (`--rem` / `--add`) — jj's colours without jj's underline — so its removed parts stay red and its added parts green, its kept text in the line's ink; a removed or added line, and every side-by-side cell (even one holding the other side's runs under a `-------` term), shows only its fill and ink. The switch changes only the drawing (the app reloads nothing); the lines stay jj's. There is one style, jj's: no underline, no strikethrough.
- **Diff options** (2026-11-14, Story 10.33, sync #26): `options={{ whitespace, context }}` adds the last control of the toolbar, an icon-only ghost MenuButton (`view-options` + chevron, no text), named "Diff options — ‹whitespace›, N context lines"; its glyph turns `--accent` while whitespace ≠ show all or context ≠ 3. Rows: *Whitespace* — Show all whitespace (`jj diff`), Ignore changes in amount (`jj diff -b`), Ignore all whitespace (`jj diff -w`), an app setting; *Context lines* — 0, 1, 2, 3 ("jj's default"), 5, 10, 20 plus an off-list value in order, none checked when jj cannot read it (jj's `diff.color-words.context` at user scope, as in Settings › General › Diffs); then the note. While whitespace is ignored, lines that changed only in whitespace read as unchanged (DiffHunk); a file left with no hunk shows "Only whitespace changed in this file." (`onlyWhitespace`). The summary and Viewed stay exact.

  ~~~jsx
  <DiffView file="lib/a.dart" options={{ whitespace: "all", context: 3 }} onOption={apply} tools={layoutToggle}>…</DiffView>
  ~~~
- Viewed folds the diff into "Viewed — diff folded away. Click to show it again." — a button whose focus ring sits inside the well (it clips).
