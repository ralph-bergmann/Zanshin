The inspector's diff block — path, layout toggle and "Viewed" over the hunks of one file, as `jj diff`'s default color-words lines.

~~~jsx
<DiffView file="lib/onboarding/swipe_controller.dart" viewed={v} onViewedChange={setV}
  tools={<Segmented size="sm" value={mode} onChange={setMode} options={[{ value: "unified", icon: "split-inline", title: "Unified" }, { value: "split", icon: "split-side", title: "Side by side" }]}/>}>
  <DiffHunk context="class SwipeController" mode={mode} selectable selected lines={[" 12:12|  final double threshold;", "~13:13|  void onEnd({+DragEndDetails d+}) {", "+:14|{+    _commit();+}"]}/>
</DiffView>
~~~

- Surface: `--code-bg` well, 1px `--fl-border`, 12px radius; JetBrains Mono 11px / 1.65.
- **Rows** (Story 5.10): each row shows its left (old) and right (new) line number, right-aligned in columns as wide as the hunk's largest number and outside the selection, then its text — no sigil column. Context: faint numbers, muted text. Removed: left number and text in `--rem` on `--rem-bg`. Added: right number and text in `--add` on `--add-bg`. **Changed** (an inlined line holding both sides' words): both numbers in their hue (left `--rem`, right `--add`), no fill, `--text` ink. A conflict header (`diff.color-words.conflict = "pair"`): `--text-dim`, no numbers. Hunk headers in `--hunk` on **`--hunk-bg`** (data — not `--accent-soft`, which is selection). Minus sign is a real "−".
- **Lines** are written `"<kind><left>:<right>|<text>"`: `" 12:12|…"` context, `"-14:|…"` removed, `"+:14|…"` added, `"~13:13|…"` changed, `"#|<<<<<<< Created conflict"` a header. One old line spread over several new ones repeats its left number (`"~13:13|…"`, `"~13:14|…"`). Changed words: `[-…-]` around a left-side run, `{+…+}` around a right-side one, on any line. A string has no escape: code that holds `[-`, `-]`, `{+` or `+}` (`s[-3:]`, `i++}`) goes in the object form `{ t, l, r, s, runs }`, `runs` as `[text, "rem" | "add" | null]`. Older git strings (`"+…"`, `"-…"`, `" …"`) still parse, without numbers.
- **Changed words**: each run lies on the stronger tint of its side's hue (`--rem-word-bg` / `--add-word-bg`, the line's full height) and its glyphs turn `--text` (red or green text on a stronger tint falls under 4.5:1 — Control states rule 6). A changed line always shows both colours. A removed or added line whose unchanged text is only blanks — an inserted line, a block over the inline limit's new lines, a new or deleted file — keeps no marks: its fill says it all. In the app the lines and runs are exactly what `jj diff` prints with no `ui.diff-formatter` (jj-lib's line and word diff, the CLI's inline rule: a block is inlined unless its words alternate between the sides more often than `diff.color-words.max-inline-alternation`, default 3), painted under the text, so a selection's highlight lies on top of a mark.
- Viewed folds the diff into "Viewed — diff folded away. Click to show it again." — a button whose focus ring sits inside the well (it clips).
- Keyboard · VoiceOver · Reduce motion: the toolbar's controls, each hunk and the folded row are Tab stops · the code is selectable text (the numbers are not); word marks are visual only, VoiceOver reads the line's text as before · static.
