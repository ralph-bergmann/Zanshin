The Zanshin brand mark (Nami — three gold waves on indigo); use it wherever the product identifies itself: project capsule, dialogs, about, splash.

~~~jsx
<NamiMark size={28} chip />   {/* top-bar project capsule */}
<NamiMark size={128} />        {/* app icon / about */}
<NamiMark size={64} bare />    {/* waves only on the night canvas */}
~~~

- Never recolour the waves, never place them on a non-indigo tile, never rotate. The enso marks are retired.
