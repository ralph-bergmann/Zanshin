Focus — one ruleA 2px --focus-ring outline 2px outside, keyboard only, settling in from 3px farther out. Three exceptions: rows in lists, menus and scroll areas, flush segments and rail buttons draw it 2px inside (their containers clip) · graph cards 3px out (clears the selection halo) · text entry shows border + halo on any focus (the caret is the state). Menu rows show focus as their highlight.
FreeCompact
Disabled — one value.4 on the whole control. No hover, no press, no tab stop. Give the reason whenever the control would otherwise look broken: aria-disabled on the control, the tooltip on its wrapper (Flutter: Tooltip(IgnorePointer(…)) + Semantics(enabled: false, hint: reason)).
Selected — where vs. what--fl-on (neutral) = where you are: navigation, tabs, segments, the file whose diff shows. --accent-soft = what you picked among data: a project, a configuration — and the keyboard row of a field-attached list. Moon border + ring = the selected change.

Menu highlight — two kindsCommand menus (context, drop, project, select list, text menu): focus moves into the menu, ↩ runs a command → solid accent + ink. Field-attached lists (search menu, suggestions): focus stays in the field (aria-activedescendant), the row is a candidate → hover --fl-hover, keyboard row --accent-soft + accent icon; what the graph shows carries a check, not a fill.
