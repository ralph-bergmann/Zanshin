Callout that previews a rail panel on hover (bookmarks, workstreams, reviews, undo timeline); click the rail button to pin the real panel.

~~~jsx
<Callout icon="workstream" title="Workstreams">
  <CalloutText>No workstreams yet. Create one with <code>jj workstream new</code>.</CalloutText>
</Callout>
~~~

- Empty states are one quiet sentence, often with the command that fixes them.
