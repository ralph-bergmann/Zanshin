Folds a linear run of ≥ 2 changes into one stacked card; click to expand.

~~~jsx
<StackCard count={2} subject="exp: generate providers for settings" from="uwqmpxsv" to="kzrmqlnt" author="Ralph" date="1h – 50m" />
~~~
- Keyboard · VoiceOver · Reduce motion: as ChangeCard; ↩ expands the stack · button "Stack of 3 changes, …" · static.
- `from`‥`to` — the id range oldest‥newest (`from` = the bottom member, `to` = the top member), the way the date runs (sync #23). The subject is the top member's.
- `date` — the stack's period, oldest – newest, in the card's date form ("1h – 50m", "Sep 18, 2019 – Dec 11, 2025"). It stays (sync #23: a stack's stretch carries no mark, so the card names the time): on a narrow card the author gives way first, then the date takes its short form when that is narrower — always with the year: "Sep 2019 – Dec 2025", "Apr – Dec 2025", "Jun 3 – 24, 2025", one day "Jun 3, 2025" — then ends in "…"; it goes only when not one character fits. The author stands only beside the full date.
