Flutter

// Einmal ganz unten im Fenster-Scaffold. Beide Gradients sind const-Decorations,
// Flutter cached den Shader; ein RepaintBoundary hält den Layer statisch.

class ZanshinCanvas extends StatelessWidget {
  final Widget child; final bool dark;
  const ZanshinCanvas({super.key, required this.child, required this.dark});

  static const _nightBase = BoxDecoration(gradient: LinearGradient(
    begin: Alignment.topLeft, end: Alignment.bottomRight,
    colors: [Color(0xFF1A2038), Color(0xFF12162A), Color(0xFF0E1224)],
    stops: [0, .68, 1]));
  static const _dayBase = BoxDecoration(gradient: LinearGradient(
    begin: Alignment.topLeft, end: Alignment.bottomRight,
    colors: [Color(0xFFF7F4F0), Color(0xFFF0ECE7), Color(0xFFE8E3DD)],
    stops: [0, .68, 1]));

  static BoxDecoration _glow(Color c) => BoxDecoration(gradient: RadialGradient(
    center: const Alignment(-.8, -1.15), radius: 1.35,
    colors: [c, c.withOpacity(0)], stops: const [0, .62]));

  @override
  Widget build(BuildContext context) => RepaintBoundary(
    child: DecoratedBox(
      decoration: dark ? _nightBase : _dayBase,
      child: DecoratedBox(
        decoration: _glow(dark
          ? const Color(0x3D6078B2)   // 24 %
          : const Color(0x33DCA85B)), // 20 %, warm
        child: child)));
}

Regeln

  • Nur das Fenster-Canvas bekommt den Gradient. Sidebar, Karten, Dialoge liegen als halbtransparentes Weiß bzw. Weiß-auf-Dunkel darüber (white @ 3 % night, warmweiß #FFFDFA @ 58–72 % day) — reines Alpha-Blending, kein BackdropFilter.
  • Fensterkante: 1 px Hairline (white @ 9 % / #3A2E22 @ 14 %) plus ein weicher Drop-Shadow. Zusammen mit dem Indigo-Ton endet das Zanshin-Fenster sichtbar, egal welches Yaru-Programm daneben liegt.
  • Kein Noise, kein Blur, keine Animation im Hintergrund — der Gold-Akzent bleibt Statusfarbe (aktueller Change, Fortschritt), nicht Dekor.
  • Yaru-Widgets weiter unverändert nutzen; nur scaffoldBackgroundColor auf transparent setzen und das Canvas darunter legen.
