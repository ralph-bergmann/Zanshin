### #5 · 2026-10-11 · Search field replaces the revset dropdown (top bar › View)
The View capsule now opens with one search field instead of the revset dropdown: `[scope ▾ | query | jj log variant ▾]`, followed as before by the gap legend, the change count and View options. Explored in `Search Study.html` (kept for experiments); the client ships the "refines" variant. State before the change: `archive/v9 Revset Dropdown/`.
Files: `graph-search.jsx` (component `GraphSearch`), `search.css` (all `.gs-*` classes), `revset-config.jsx` (store exports, `cfg.base`, search revsets `q:{…}`, `canRefine`), `app-float.jsx` (`.fl-tc`), `float.css` (`.fl-top` grid).

- **Scope pill (`.gs-scope`)** — icon only for "Any", icon + label for a scope. Two kinds, grouped in its menu (`.gs-scopes`): *Go to* (Change, Bookmark) selects a change and leaves the graph alone; *Filter by* (Author, File, Description) redraws the graph. Typed prefixes `c: b: a: f: d:` switch the scope; Backspace in an empty field returns to Any. While a search filters, the pill is tinted moon (`--accent-soft` / `--accent`). Below 1100px the pill drops its label (icon only).
- **Suggestions (`.gs-pop`)** — menu material (`--fl-sheen` + `--fl-bg-solid`, radius 12, the `fl-pop` entrance). Rows `.gs-row` 34px, highlighted row = `--accent-soft`; group headers = the small-caps menu header style; the match is underlined in `--accent` (`.gs-m`); paths dim their folder part (`.gs-d`); counts in tabular numerals; `not in view` tag (`.gs-tag`). A footer (`.gs-ft`) states what Enter does: the full `jj log -r '…'` command, or "Selects the change — the graph stays as it is". Empty field: recent searches (go-to and filters) with a hover **Save**.
- **Variant segment (`.gs-rev`)** — new rule: `$ jj log` means "this command draws the graph". While a search narrows it, the segment reads **`in jj log`** (no `$`, label in `--text-muted`, `.is-base`) and its menu starts with "Search within" and hides variants that can't match together with the search (logic only: author / committer / subject / description hold one value per change, so a pinned value — exact or `mine()` — clashes with a pattern that can't match it; `files()` and two patterns never clash). A saved search becomes a filter (`cfg.base` keeps the variant it narrowed), is selected, and the segment flashes once (`gs-flash`, moon ring). Primary buttons in these forms are moon fills with `--accent-ink`.
- **New glyphs** — change (node on a line) and description (three lines); bookmark reuses `BookmarkGlyph`; authors show an initial avatar (`.gs-av`).
- **Top bar layout** — `.fl-top` columns are now `minmax(max-content,1fr) minmax(0,max-content) minmax(max-content,1fr)`: on narrow windows the centre gives way, the side groups keep their size.

### #6 · 2026-10-12 · One search menu, default search, no Save (top bar › View)
The search field loses its second menu and Save: `[menu ▾ | query | ✕]`, followed as before by the gap legend, the change count and View options. Explored in `Search Study.html` (model "One menu"). State before the change: `archive/v10 Search Field/`.

- **One menu (`.gs-scopes`, now 420px, scrolls)** — the dropdown left of the field, in this order: the **default search** (tag `Default`, `.gs-tag`) · the other jj log variants, built-ins and configurations (`.gs-vrow`: `$` glyph, name, expression) · separator (`.gs-msep`) · *Go to* (Change, Bookmark) · *Filter by* (Author, File, Description), each with its prefix · separator · **Edit Configurations…** (`.gs-edit`, muted label). The docked client's dialog is unchanged.

→ Design system: rework the **Search field** card (default/empty, typed search, variant shown by name with `$`, focused with Recent, the one menu, narrow) and drop Save, the variant segment and the save form; remove the search additions from the **Revset menu** card ("Search within", hidden-variants note — in the floating client the variants now live in the search menu); add **Default search** to the configurations dialog card (switch row, `Default` tag, selectable built-ins); update the **Top bar** View capsule anatomy (`[menu ▾ | query | ✕] · gap legend · count · View options`); replace the rule "`$` = draws the graph · `in` = where the search runs" with "`$` marks a variant that draws the graph"; add the `$` row glyph (`.gs-dollar`: mono 600 13px, `--text-dim`, moon when selected).

### #7 · 2026-10-14 · Graph: Free layout (default), one line per parent, day axis
The graph gets a time-based layout and new line routing. Explored in `Graph Lines Study.html` (the team picked variant B). State before the change: `archive/v11 One Search Menu/`.
Files: `graph-layout.jsx` (new — layout engine moved out of `graph-view.jsx`: `computeLayout`, `groupStacks`, `GraphLayout`), `graph-view.jsx` (`.gtime` day axis, guides, cuts), `graph-gaps.jsx` (`placeGapMarkers`), `app-float.jsx` (View menu › Layout).
- **Layout: Free · Compact** — View menu segment, Free is the default (storage key `zanshin.graph.layout2`); "Time" is removed. *Free:* commits close in time stand close together across branches; gaps grow with the time between commits, log-damped and capped at 3 pitches; an edge is always at least one pitch long. *Compact:* rows = generation depth, as before.
- **Day axis (Free only)** — left gutter (88px, `.gtime`, sticky; in the floating client it sticks right of the rail / pinned panel): one label per calendar day at the height of that day's lowest commit — "Today", "Yesterday", "Sep 23" (`.gtime-label`: mono 11px, `--text-muted`, `--card-solid` pill, 1px `--border`) — and a dashed guide between days (`.gguide`, `--border-strong`, dash 2 6). The minimap uses the same day labels.
- **Lines: one per parent → child pair** — every line has its own exit on the parent's top edge and its own entry on the child's bottom edge (first parent: bottom centre; other parents beside it, farther parent = farther out; dashed lines through the same hidden parent share one entry). Forks turn just above the parent, merges just below the child; horizontal runs stack in tracks 3.5–6px apart and nest instead of crossing. A merge whose parent lane is taken climbs the gutter between columns. In Free, a run that would pass behind a card detours through a gutter.
- **Exit fan-out rule (width-dependent)** — exits sit 12px apart while they fit between 18px from the centre and 18px from the card edge; with less width they squeeze down to 7px; beyond that the outermost lines share one exit and split above the card. Extra entries: 16px apart, down to 8px.
- **Line interruptions keep their distance** — a crossing bridge (12×10 break) keeps ≥12px of visible line to the next bend or card; if the horizontal line has no room there, the vertical one breaks instead. Gap markers never sit right at a card: on a hidden merge's shared stem the marker keeps 12px of line on both sides (the router places that merge's run as far from the card as the gap allows); when nothing fits, the marker takes the middle of the longest free stretch.
→ Design system: update the **Graph** pattern (edge anatomy: exit/entry ports, tracks, gutter detour, bridges with the 12px clearance, the fan-out rule with its three stages at 400/240/160px card width); add a **Day axis** component card (label + guide, Free layout); update the **View menu** card (Layout: Free · Compact, Free default; Time gone); note in the gap-marker card that markers keep 12px of line to cards.

### #8 · 2026-10-14 · Graph: Free and Compact share their columns, day labels on the dividers
Free looked wider than Compact: each layout chose its own columns (different order, sometimes a different count) and Free added an 88px day gutter. State before the change: `archive/v12 Free Layout/`.
Files: `graph-layout.jsx` (one lane packing + column order for both layouts, `colMemo`), `graph-view.jsx` (columns from the collapsed graph; minimap day pill), `graph.css` (`.gtime` without the gradient), `float.css` (`.is-float .gtime`, `.is-float .gtime-label`).
- **One set of columns** — switching Free ↔ Compact only moves cards up and down; width and column order stay. Two branches share a column only if they are apart in both layouts (and in Compact never with the upper one starting right above the other's tip). Of the packings with the fewest columns, the one whose lines cross least wins.
- **Stacks** — columns come from the collapsed graph; an expanded stack keeps its stack's column, so expanding never moves a card sideways.
- **Day axis without a gutter** — Free reserves no extra width. Each day's label (`.gtime-label`, unchanged pill) sits on the dashed divider below that day's first commit, at the left edge, sticky (floating client: right of the rail or pinned panel). The band around a divider never holds cards, because days never interleave in Free. The oldest day's label sits below its first commit. Reading upward: label = "this day starts here".
- **Minimap** — in Free the current-day pill names the day the viewport centre is in (labels mark a day's bottom edge).
→ Design system: update the **Day axis** card (label on the divider, no gutter); add the rule "layouts share their columns: switching only changes heights" to the **Graph** pattern; the View menu card needs no change.
