## Deferred from: code review of 3-2-handle-module-ffi-strings-zanshin-ffi-version (2026-06-15)

- **`build.rs` git-SHA stamp goes stale under git worktrees / shallow clones** [`crates/zanshin-ffi/build.rs:20`] — `cargo:rerun-if-changed=../../.git/logs/HEAD` assumes `.git` is a directory two levels up.
