## Goal

Supply the commit-graph's data and layout from jj. Stories 4.1–4.9 built a `jj log`-parity lane graph, which 4.12 removed: the commit-graph view (Epic 10) draws the design's layered layout (rows shared by several commits, packed lanes, routed orthogonal edges), computed in pure Dart on `zanshin_core`'s worker isolate. The epic now delivers the whole revset's index-only topology plus op-pinned lazy card content (4.10), its compact wire and lazy Dart view (4.12), the layout engine (4.11) with commit stacks (4.13), and — from the floating-client export `e74ced3` — one shared set of columns for Free and Compact (4.14) and line router B as a `zanshin_core` library (4.15).

## Requirements & Constraints

- **Complete topology per operation, lazy content per page.** No row-range windowing. The topology is index-only per node; card content loads per visible page, pinned to the topology's operation, and writes nothing.
- **Pass-through, never decide:** revset, prioritize, short prefixes, anchors, mode, lane order and budget are caller arguments; Rust bakes in no default. `zanshin_core` exports editable pre-fills (anchors `["trunk()", "present(@)"]`, log defaults from `logDefaults()`).
- **Null for absence;** decoders throw on a missing required field.
- **Product layout scope:** modes `free` (default) and `compact`; lane orders `compact` (default) and greedy. `time` and `optimized` are dropped and never ported. No lane-order control in the UI.
- **The layout is independent of card width and height** (W, H never appear in a layout request). A layout is requested once per operation, never on resize. Anything W/H-dependent (route geometry) is a separate stage keyed by the metrics.
- **Columns never move for presentation switches:** a stack toggle or the "Group stacks" switch never moves a column (4.13); with 4.14, a Free ↔ Compact switch never changes width or column order either — only rows move.
- **Deterministic integer engine:** byte-identical to `docs/graph-layout.md` (GLD); total sort keys; floor division; budget "stops the phase".
- **No elided counts** anywhere. Performance numbers are recorded in specs per store kind (loose vs packed); no timing assertions in tests.

## Technical Decisions

- **GLD is the engine's contract** (`docs/graph-layout.md`; the spike's `SPEC.md` is a pointer). Every behavioural change is a dated GLD amendment first, implemented in the spike's Dart reference (`spikes/graph-layout-ab/dart/`) and its recorder, then ported byte-identically into `packages/zanshin_core/lib/src/graph_layout/`, with goldens regenerated by `node tools/goldens.mjs`. Dart-only features (the `compact` order, stacks, and now joint columns) have no Rust reference; the spike's Rust keeps its per-mode greedy as history.
- **Relevant GLD parts:** §2 input (repeated targets → one parent per target at its first position, `direct` if any is), §4.2 layering (compact y = generation rows; free y = clamped time, U = 16, gap curve, cap 48 units, one pitch per edge), §4.3 lane packing (continuation child, interval [a, b) with the one-row buffer, first fit, O(n log n) via per-lane top-two b′ plus a segment tree over lanes), §4.5 routing, §4.7 the `compact` order (segments = straight-edge chains of the greedy packing, windows cut where reservations connect, cost U·(400·X + 4·Len) + κ·Σ col·(b − a), κ = 24, reach 8, 16 rounds, budget 2,000,000; trunk column fixed; empty columns dropped), §4.8 stacks (columns from the ungrouped layout, rows from the grouped graph), §7.3 invariants I1–I7, §13 the product engine (import rule: core imports only `dart:typed_data`, `package:meta`, itself).
- **Standing rules:** no type named `GraphLayout` (10.1's app-side contract) or `GraphRef` anywhere in `packages/`; the engine types are public but stay out of the `lib/zanshin_core.dart` barrel (10.12 exports them); a run that decides something new appends it to `decisions-review-4-10-to-4-13.md` under its own `### 4.x` heading.
- **Engine guardrails:** flat typed arrays and CSR, no per-node objects or maps on hot paths, hand-written monomorphic sorts (never `List.sort`), tunables `const` or request parameters (hot reload), worker stays `Isolate.spawn`ed. Contract violations throw `LayoutContractException` (V1–V5), never a repaired layout.
- **4.14 shared columns (done):** every request lays out both vertical models (compact U = 1, free U = 16). A node's §4.3 interval is computed in each model; it fits a lane iff disjoint from that lane's intervals in both (continuation rule unchanged). Packed in compact and in free visit order, the fewer lanes kept, compact on a tie; the other model's test is a per-lane sorted array with prefix maxima (`LaneIntervals`, `shortcut:` to a balanced tree, not needed at 100k). Greedy: π = identity. The joint `compact` order: windows = components under "overlap in either model", cost 16·c_c + c_f, skip per model, work units per model (with one model it is §4.7's, byte for byte). Stacks run on the joint ungrouped columns with the requested mode's rows (design default compaction 9 → 7). Output: lane/col/`lanes` identical in both modes (I8). Grid format versions 3 / 4 add `nodeDays` (dk of the clamped T in both modes; root `GraphGridView.noDay`; stack node = newest member's). The spike keeps per-mode as its default; `--columns joint` (Dart-only) is the reference the product equals byte for byte and all goldens come from. Amended GLD §2, §3, §4.2, §4.3, §4.7, §4.8, §6, §7.2, §7.3 (I8), §13.
- **Not copied from the export** (4.14): its whole-lane optimizer, exact chain colouring and router-judged packing choice — factorial in lanes, scored with the O(E²) router, and W/H-dependent. Exact colouring was measured and rejected: on the design samples (the only inputs ≤ 40 chain heads) GL's exact colouring saves no lane (default 8, all 9 = the joint greedy count). The joint packing does widen fixture-medium/large `all()` in Compact (3 → 4 lanes, mean width +28 % vs per-mode compact, +18–20 % vs the larger per-mode width) and narrows synth-100k in Free (mean width 98.6 → 42.9 vs per-mode free); the layout costs 2–3× the per-mode time (spec-4-14 § Measurements).
- **4.15 router B (done):** GLD §14 (dated §4.5 / §7.2 / §12). `lib/src/graph_layout/router.dart` (engine core imports), exported from the barrel as `RouteClasses`, `RouteMetrics`, `RouteGeometry`, `RouteBridges`, `routeSyncNodeLimit` (no other engine type). Input = the grid's raw arrays (rows, cols, U, free, edge from/to/kind) + the topology's `parentCount`. Class stage per layout, no W/H: straight / fork / merge-adjacent / merge-up / gutter (column free = no node strictly between), the first free gutter from the child, Free detours by the 1–12 unit rule, gutter steps ±6 px, shared deep entries only at `parentCount` = 1 with ≥ 2 Indirect edges; reports `directFallbacks`, `overfullGutters` (+ per-edge `fallbackEdges`, which also flags a Free gutter line with no free gutter). Geometry stage per `RouteMetrics` (W, H, gapX 56, gapY 48, pad 56), GL's formulas in doubles: exits, entries, room / clusters / tracks via indexes, polylines (2/4/6 points, CSR), entry ports (CSR), verticals by x, horizontals by y; reports `overfullClusters` (+ `overfullEdges`), `unavoidableCrossings`; `bridges(x0, y0, x1, y1)` = half-open window query, no all-pairs pass. The engine's `route` / `blocked`, grid format and goldens are unchanged. **Where it runs:** UI side, class once per layout, geometry per metrics; synchronous up to `routeSyncNodeLimit` = 20,000 visible nodes, `Isolate.run` above (10.4 wires it), never a worker request (measured: 1.5 ms at fixture-large-all, 3.8 ms at synth-10k, 40.7 ms free / 27.9 ms compact at synth-100k, AOT).
- **Worker / wire:** `RepoHandle.graphLayout(...)` re-runs `zanshin_graph_topology` per request (ADR-0002: no state in the worker or on the handle) and replies with `GraphTopologyView` + `GraphGridView` as one `TransferableTypedData` each. Since 4.14 timestamps load for every request (compact pays ~59 ms packed / 1.24 s loose at 10k).
- **Rust side (done, stable):** only `zanshin-jj` imports `jj_lib`; externs only in `zanshin-ffi`. FlatBuffers envelope, request tables with appended `RequestKind`, `Payload` order is the wire discriminant, regenerate with `cargo make codegen`. jj reference pin `v0.46.0` (`../jj`, read at the tag).
- **Tests and coverage:** the coverage ratchet is Rust-only, so Dart engine tests are the safety net: unit tests, goldens, invariants on ≥ 1,000 seeded DAGs, real-cdylib worker tests. Fixtures are committed and never regenerated. Dev tools (benchmarks, differential scripts, the spike's oracle) stay outside the gate.

## UX & Interaction Patterns

The view never decides rows, columns, route classes, buckets or a free y — it maps the engine's output (and, with 4.15, the router's geometry) to pixels. Switching Free ↔ Compact, toggling a stack or "Group stacks" moves cards only vertically. Indirect edges draw dashed, Missing edges as stubs, without counts. Edges are coloured by state, not by lane.
