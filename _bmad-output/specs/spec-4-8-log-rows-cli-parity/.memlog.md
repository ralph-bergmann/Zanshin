- (direction by user) Ralph requests Epic-4 follow-up: per-commit lane cross-section + display metadata in one row, the way jj CLI renders 'jj log' (analysis 2026-08-23). Goals: (a) performant calls/rendering, lane/commit mismatch impossible; (b) content parity with jj CLI log (not colors/layout) so jj users recognize the graph.
- (decision by user) Scope cut: ONE story 4-8 end-to-end (zanshin-jj enrichment -> zanshin-graph row model -> schemas/envelope.fbs -> zanshin-ffi -> Dart models), no 4-8/4-9 split (Ralph 2026-08-23; 4.6 precedent shows the span is buildable).
- (decision by user) Rows carry per-row pass-through lanes (active_lanes): every row is self-contained renderable like a renderdag row (Ralph 2026-08-23). Supersedes epic-4-context 'no per-row pass-through-lane info until the UI asks' — the UI has now asked; payload duplication accepted.
- (decision by user) zanshin-jj defines the jj v0.42.0 builtin [revset-aliases] set (builtin_immutable_heads()=trunk()|tags()|untracked_remote_bookmarks(), immutable_heads(), immutable(), mutable(), visible(), hidden(); trunk() exists) AND rows carry an immutable flag (Ralph 2026-08-23). Without the aliases neither the CLI default log revset nor the diamond glyph semantics are reachable.
- (decision) Parity baseline pinned: jj v0.42.0 builtin templates (builtin_log_compact + builtin_log_node) + config defaults (revsets.log, log-graph-prioritize=present(@), ui.log-synthetic-elided-nodes=true). CLI files read at tag: cli/src/commands/log.rs, cli/src/graphlog.rs, cli/src/config/{templates,revsets,misc}.toml. Parity is CONTENT (fields/flags/rows/order), never terminal UX/colors/layout (NFR-R-2 reading).
- (constraint) Atomicity by construction: one zanshin_graph_slice call = one load_at_head snapshot (ADR-0002); metadata is extracted during the SAME single stream pass and emitted inside the SAME Row as the lane assignment. No parallel arrays, no join key, no second FFI call to render the log view — this is what makes lane/commit mismatch impossible.
- (constraint) Performance: keep the single-pass stream (no second walk, no materialized cache — ADR-0002 AC-4 holds); per-call O(1) setup indexes only (refs reverse index from View, immutable containment fn, IdPrefixContext for shortest prefixes), amortized O(1) per row; no per-row revset evaluation. Soft NFR <1s @ 10k incl. metadata; no perf gate while WIP (100-commit algorithmic correctness test remains the only mandated check).
- (constraint) ACL unchanged (FR-JJ-16): metadata extraction + aliases live in zanshin-jj (sole jj_lib importer); elided-row splice + lane assignment + row model live in zanshin-graph (stays jj_lib-free); the extern fn stays zanshin_graph_slice in zanshin-ffi (signature may change in place — WIP breaking changes allowed, all callers updated in the same change, codegen committed).
- (constraint) Pass-throughs (FR-JJ-17), CLI-applied defaults pre-filled and editable, never silent: revset + prioritize (existing), synthetic_elided (bool, default true = ui.log-synthetic-elided-nodes CLI default), short_prefixes revset (default = CLI revsets.log default expression; disambiguation source for shortest id prefixes). Backend classifies/offers; UI decides.
- (capability) CAP-1 enriched log row: each GraphRow carries the jj-log display metadata catalog (ids + shortest-prefix lengths, author identity, committer timestamp, refs, glyph/label flags, description first line; catalog in cli-log-parity.md); success = committed-golden row-by-row equality with jj log content on fixtures + in-test constructed edge repos.
- (capability) CAP-2 self-contained lane cross-section: each row adds active_lanes so it renders without neighbor knowledge; success = structural invariant tests (every routed edge crosses only rows listing its lane; node lane consistent) over medium fixture incl. octopus.
- (capability) CAP-3 synthetic elided rows: Indirect edges materialize as elided rows placed and linked as the CLI does (child edge becomes direct to the elided row, elided row links direct to target, emitted after the child row), toggleable via synthetic_elided; success = row sequence matches CLI placement on an eliding revset; toggle off restores today's Indirect-edge-only stream.
- (capability) CAP-4 CLI default view evaluates: with the builtin aliases defined, the CLI default log revset present(@)|ancestors(immutable_heads()..,2)|trunk() parses/resolves/evaluates in zanshin-jj and the immutable flag matches immutable()=::(immutable_heads()|root()) containment; success = default-revset walk succeeds on fixtures and flags root+trunk ancestry immutable.
- (capability) CAP-5 wire + Dart surface: extended GraphSlice crosses the existing zanshin_graph_slice envelope (schema edited in place, flatc/cbindgen/ffigen outputs regenerated+committed) and packages/zanshin_core exposes the new params + typed row models; success = real-cdylib Dart decode roundtrip incl. elided rows and re-derive-after-external-op test extended to metadata.
- (assumption) Backend ships semantic flags (working-copy/immutable/conflict/root/elided), never glyph strings — glyph choice (@ diamond x o ~) is UI mapping per the backend-exposes/UI-decides rule; the flag PRIORITY order for glyph selection is recorded as CLI content in the companion.
- (assumption) Edge-state test coverage (divergent, hidden, conflict, empty, remote bookmarks) is constructed in-test via jj-lib write helpers (test-helpers precedent, Story 4.6 add_commit_off_root) — committed fixtures are NEVER regenerated (they lack these states; regeneration shifts the revset oracle). Golden parity values are verified against real jj v0.42.0 output once at authoring time and committed; runtime/tests never shell to jj (NFR-R-1).
- (question) OPEN: repo/user jj-config overrides (custom immutable_heads()/trunk()/revset-aliases in the user's jj config) are NOT honored in 4-8 — builtin defaults only. A CLI user with customized aliases will see diverging diamond/default-view behavior. Honor .jj config in a later story? (Needs a config-read surface zanshin-jj does not have yet.)
- (decision) Non-goals fixed: colors/glyph rendering/layout/themes (UI scope); windowing/--limit/--reversed (deferral unchanged, 4.4 decision); op-log graph parity; cryptographic-signature display (CLI default off); full/multi-line description (get_change's job); zanshin_change and MCP surfaces untouched; no materialized cache; no jj-config override reading (see open question).
